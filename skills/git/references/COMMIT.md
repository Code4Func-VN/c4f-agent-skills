# Quick Commit

## Format

```
type(scope): subject        ← max 72 chars, imperative, lowercase
```

## Types

| # | Type | Use |
|---|------|-----|
| 1 | `feat` | New feature |
| 2 | `fix` | Bug fix |
| 3 | `refactor` | Restructure, no behavior change |
| 4 | `perf` | Performance |
| 5 | `test` | Tests only |
| 6 | `docs` | Docs only |
| 7 | `chore` | Deps, config, tooling |
| 8 | `ci` | CI/CD |

## Workflow

```bash
git add -p                           # Stage intentionally
git diff --cached --stat             # Review staged
git commit -m "type(scope): subject"
```

Split if: mixed types, mixed scopes, >10 files, deps+code.
Single if: same type/scope, ≤3 files, ≤50 lines.

## Good

```
feat(search): add autocomplete suggestions
fix(api): prevent duplicate webhook deliveries
chore(deps): upgrade react from 18.2 to 19.0
```

## Bad

```
feat: Changes                  ← vague, capitalized
fixed the login bug.           ← no type, past tense, period
```

## Never

- AI attribution ("Generated by", "Co-Authored-By: AI")
- Period at end of subject
- Past tense ("added", "fixed")
